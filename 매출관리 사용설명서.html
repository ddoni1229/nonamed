1

상단 요약 (KPI)

화면 맨 위 4개의 카드로 핵심 숫자를 한눈에 봅니다. 우측 요약 접기/펼치기 버튼으로 숨길 수 있습니다.

오늘 매출
오늘 일자의 매출 합계와 건수
거래 건수
현재 선택된 기간의 전표 건수
기간 매출 합계
화면에 표시된 전표 기준 합계 금액
주문 대기
주문 상태(완료 전) 전표 건수
2

화면 탭 구성

매출 데이터를 4가지 방식으로 봅니다. 탭 오른쪽에는 최근 전표 히스토리가 가로로 표시되어, 클릭하면 해당 전표 수정 화면으로 바로 이동합니다.

조회
전표 단위 목록. 가장 기본 화면이며 상태 변경·인쇄·정렬이 가능합니다.
상세
전표를 품목 라인 단위로 펼쳐서 봅니다. (일자·전표·거래처·품목·수량·단가·금액)
기간요약
거래처별 카드 + 품목별 집계. 1페이지 인쇄 지원.
미수금
거래처별 전일잔액·매출액·수금액·잔액 집계.
3

기간 · 검색 필터

기간 선택
전체 · 금일 · 전일 · 다음일 · 이번주 · 다음주 중 선택. "전체"를 고르면 우측에서 날짜 범위를 직접 지정할 수 있습니다.
상태 필터
주문 완료 또는 전체로 필터. 탭처럼 눌러서 분류합니다.
검색
전표번호·거래처·품목·담당자로 검색. 결과는 즉시 반영됩니다.

결과 값(건수·합계)과 미수금 집계는 모두 상단 기간 조건을 따라갑니다.

4

조회 테이블

순번 · 상태
행 앞에 순번(No)이 붙고, 상태 칸은 드롭다운으로 변경합니다. 주문→완료로 바꾸려면 모든 품목코드가 매핑되어 있어야 합니다.
열 위치 변경
열 제목을 드래그해서 순서를 바꿉니다.
열 너비 조절
열 제목 오른쪽 경계를 드래그하면 너비가 바뀌고 저장됩니다. (조회·상세·미수금 공통)
화면 설정
우측 상단 화면 설정에서 표시할 열과 순서를 켜고 끕니다.
인쇄 열
각 행의 🖨 버튼으로 그 전표의 거래명세서를 바로 인쇄합니다.
전표 열기
행을 클릭하면 수정 화면(매출 입력)으로 열립니다.
5

새 매출 입력

제목 옆 새 매출 입력 버튼 또는 F2로 입력창을 엽니다. 키보드만으로 빠르게 입력할 수 있습니다.

  1. 거래일자에 커서가 위치합니다. 일(日) 칸에서 시작해 Enter로 다음 칸 이동.
  2. 거래처를 입력하면 검색 팝업이 뜨고, 방향키+Enter로 선택하면 담당자 칸으로 이동합니다.
  3. 품목코드 칸에 코드나 품목명 키워드를 입력하면 검색 팝업이 뜹니다. 선택 시 규격·단위·단가가 자동으로 채워집니다.
  4. 품목코드가 없는 줄은 아래에 추천 칩과 직접매핑 버튼이 나타납니다.
  5. 기본 7줄이며, 마지막 줄에 입력하면 빈 줄이 자동 추가됩니다.
  6. F8 또는 매출 저장으로 저장. 각 칸을 클릭하면 텍스트가 전체 선택됩니다.
품목코드는 필수값입니다. 매핑 안 된 품목이 있는 전표는 자동으로 주문 상태로 저장됩니다.
6

카톡·문자 붙여넣기

상단 검색창에 주문 메시지를 붙여넣으면 자동으로 전표 입력창이 열립니다.

인식 형식
양배추 1, 양배추 2박스, 양배추 x2 등. 한 줄에 품목+수량.
거래처 우선
품목만 있으면 거래처 칸으로 먼저 커서가 가고, 거래처를 입력하면 그 거래처의 저장된 단가·코드를 불러옵니다.
자동 매핑
명칭·규격이 같으면 코드가 자동 연결됩니다. 없으면 추천/직접매핑으로 연결합니다.
7

품목 매핑

거래처마다 부르는 이름이 달라도 같은 품목으로 인식하도록 연결하는 장부입니다. 상단 품목 매핑 버튼으로 엽니다.

구성
거래처명 · 거래처가 부르는 이름 · 품목명 · 규격 · 단위 순으로 정리됩니다.
등록 방법
매출 입력 중 직접매핑으로 연결하거나, 전표를 저장하면 자동으로 거래처별 매핑에 쌓입니다.
신규 품목
품목 검색 팝업에서 신규 등록(F2)을 누르면 새 품목 등록 팝업이 떠서 바로 만들고 연결합니다.
8

거래명세서 인쇄

행의 인쇄 버튼, 전표 상세의 인쇄, 또는 여러 건 선택 후 거래명세서 인쇄를 누르면 양식 선택 + 미리보기 팝업이 뜹니다.

1장 양식
A4 한 장에 명세서 1부.
2장(보관용)
한 장에 공급받는자 보관용(파랑) + 공급자 보관용(빨강) 2부.
미리보기
양식을 바꾸면 미리보기가 즉시 갱신됩니다. 여러 건 선택 시 모두 인쇄됩니다.
화면인쇄
툴바 오른쪽 화면인쇄는 현재 조회된 목록 자체를 인쇄합니다.
9

기간요약 · 미수금

기간요약
거래처별 카드(품목·수량)와 그 아래 품목별 집계표. 1페이지로 인쇄하면 A4 한 장에 자동으로 맞춰집니다.
미수금
거래처명 · 전일잔액 · 매출액 · 수금액 · 잔액 구조. 잔액 = 전일잔액 + 매출액 − 수금액. 상단 기간 조건을 따릅니다.
