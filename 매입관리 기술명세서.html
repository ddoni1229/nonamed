매입관리 기술명세서

Purchase Management — 전표 입력 · 목록 조회 · 거래처 원장 · 화면 커스터마이즈

모듈 매입관리 (maeip)기준화면 매입입력(전표)공통모듈 colconfig문서버전 1.0작성일 2026-07-14

매입관리는 전표 입력, 거래 목록 조회, 거래처 원장을 하나의 화면 흐름으로 제공하며, 모든 표·패널·문서 레이아웃을 사용자가 직접 커스터마이즈하고 코드가 부여된 "저장된 화면(뷰)"으로 재사용할 수 있는 것을 핵심으로 한다. 매입입력 화면이 기준(마스터) 화면이며, 여기서 확정된 기능은 매출·주문·품목·거래처 화면에 동일하게 반영된다.

1화면 구성

화면유형설명
매입입력 (전표)입력 팝오버거래처·일자 헤더 + 품목 라인 테이블 + 우측 정보 패널. 기준 화면.
목록 — 조회 / 상세 / 기간요약 / 미수금탭 테이블4개 탭이 각각 독립적으로 화면설정·코드를 가진다.
거래처 원장문서(리포트)거래처 클릭 시 진입. 업체 전달용 자유배치 문서.

2매입입력(전표) 화면

2.1 품목 라인 테이블

  • 각 칸을 텍스트로 직접 입력. 빈칸에서 Enter는 다음 칸으로 건너뜀.
  • Enter 이동 순서를 화면설정에서 지정 가능(탭 순서 커스터마이즈).
  • 품목명 = 품목코드 + 품목명. 품목코드는 필수이며, 없는 칸은 붉게 표시.
  • 미등록 품목은 "추천"으로 안내(직접 매핑 대신 "신규" 처리).
  • 추천 행은 배경을 회색 처리하고, 품목명·규격·수량을 제외한 나머지 칸(단위·단가·공급가액·부가세·메모·커스텀 열)의 글씨를 블러 처리.
  • 부가세는 면세 문구 없이 숫자형으로 입력.
  • 헤더와 본문의 열 너비를 정확히 일치시켜 라인이 어긋나지 않도록 함.

2.2 품목 검색 / 창 동작

  • 품목 검색창이 열린 상태에서 ESC → 검색창만 닫힘(입력화면 유지).
  • 입력 중 입력창 바깥 클릭으로 창이 닫히지 않음.
  • 검색 등 작업 중 창을 닫으면 종료 확인 알럿을 띄우고, 종료 후 재진입 시 첫 화면(빈 전표)으로 복귀.

2.3 우측 정보 패널

  • 입력값 기반으로 거래처 / 품목(매입·매출 정보 포함) / 재고 정보를 표시하는 패널.
  • 화면설정에서 패널 추가 가능 — 기존 품목정보 패널 우측으로 신규 패널이 생성(기존 패널 안에 중첩하지 않음).
  • 패널은 상/하단 구분 없이 자유롭게 이동, 너비 조절 가능.
  • 패널명 클릭 시 항목 설정 화면 표시(신규 열 추가 화면과 동일한 UI로 통일).
  • 신규 진입 시 패널에 색상 없음 → 크기/위치 변경 후 적용 버튼을 누르면 색상이 들어오고 창을 닫으면 크기 고정. 버튼을 누르지 않으면 이전 화면 그대로.

3화면 설정(커스터마이즈) 시스템

모든 표·패널·문서는 화면 설정 버튼으로만 편집 모드가 활성화된다. 편집 중에는 배경색이 바뀌어 설정 중임을 시각적으로 알린다.

3.1 공통 기능 (전 화면 동일)

  • 열 표시 / 숨김
  • 열 순서 변경(드래그)
  • 열 너비 조절
  • 커스텀 열 추가(추가 모달)
  • 계산식 열(수식 툴)
  • Enter 이동 순서 지정
  • 저장된 화면(프리셋) 코드 부여
  • 편집 중 배경색 표시

계산식 열

계산식 열은 입력화면의 열 + 거래처 정보 + 품목정보의 금액값을 모두 불러와 수식으로 조합할 수 있다.

3.2 저장된 화면(뷰) 코드 체계

  • 화면을 저장하면 코드 자동 부여(예: V-01 V-02) + 이름 지정.
  • 상단 항목/테이블 구분: 상단은 상단 a, 품목 입력 테이블은 하단 a 형태 코드.
  • 목록 4개 탭(조회·상세·기간요약·미수금)은 각각 독립 코드.
  • 저장된 화면 ▾ 드롭다운으로 전환. 현재 적용된 화면 명칭을 상단에 표시.

3.3 저장 플로우

화면 설정→화면 변경→설정 완료→저장 확인 팝업→코드 자동부여 + 이름 입력
  • 덮어쓰기가 아니라 설정 완료 시 변경값을 저장하며, 변경 적용 여부를 확인 팝업으로 묻는다.
  • 저장하지 않고 창을 닫으면 다음 진입 시 원래 화면으로 복귀.
  • 편집 중에는 조회→상세→패널→미수금으로 탭 이동 불가.

4거래처 원장 (문서)

거래처명 클릭 시 진입하는 업체 전달용 문서 화면. 상세 내역과 수금 내역을 함께 보여주며, 상단에 거래처 정보를 포함한다.

4.1 자유 편집 툴(PPT형)

  • 리본 툴바로 글꼴·크기·굵게·정렬·색상·강조 등 서식 적용(블록 선택 시 활성화, 설정 켜면 제목 블록 자동 선택).
  • 블록 자유 배치(드래그 이동·크기 조절), 문구·체크박스·그림·데이터 표 삽입.
  • 표 빈칸 우클릭 → 항목 추가: 거래처·품목·매입/매출·수금/지급 테이블의 값 연결 로딩.
  • 표 셀 드래그 선택(음영 처리), 항목 위치 좌우 드래그 변경.

4.2 내보내기

  • 버튼으로 조회 / 상세 / 미수금 화면을 각각 엑셀 자료로 내려받기.

5단가 변경

  • 상세에서 체크 시 (변경) 표시, 단가 변경 가능.
  • 단가 변경 버튼 → 금액 입력 후 적용하면 체크된 품목의 단가 칸에 일괄 반영.
  • 변경은 되돌릴 수 없으므로 완료 시 저장 확인 알럿 표시.

6공통 규칙 · 아키텍처

항목내용
기준 화면매입입력. 신규 기능은 여기서 먼저 구현.
동시 적용매입입력 변경은 매출·주문·품목·거래처에 동시 적용.
공통 모듈colconfig — 화면설정·뷰 프리셋·토스트·확인팝업·열추가 모달·패널 필드 정의를 전 화면 공용.
품목 요약전 화면에서 품목명 + 규격 형식으로 통일.
저장 위치뷰·레이아웃 프리셋은 화면별 키로 브라우저에 영구 저장.
